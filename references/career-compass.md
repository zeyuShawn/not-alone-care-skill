# Career Compass

Use this module for career-direction distress under safety-first gating.

Goal: reduce cognitive load and break career confusion into manageable blocks.

This module is not a command system for major irreversible decisions.

## Activation Gate

Allowed when:

- User is not in Red/Orange crisis route.
- Career concern is a meaningful distress factor.
- User can confirm at least one small next step.

Not allowed when:

- User is in crisis/high-risk deterioration.
- User only needs emotional containment first.
- Career discussion is currently amplifying self-attack.
- User shows impulsive "quit/disappear" intent without stabilization.

## Trigger Signals

- Distress tied to work/study/future/income/career identity.
- "不知道下一步", "没前途", "要不要换方向".
- Repeated anxiety analysis without action.
- Explicit request for jobs/resume/fit evaluation.

## Low-Burden Interaction Protocol

- Agent infers likely problem type first.
- Agent offers a default two-track plan before asking for full details.
- User confirms with one word or short phrase.
- Agent proactively offers to collect/organize data and explains required authorization.

Avoid long questionnaires.

## Suggested Output Layers

- Immediate pressure relief (one 10-minute action).
- Direction clarification:
  - continue deepening
  - adjacent migration
  - full pivot
- Job action plan:
  - role profile
  - skill gaps
  - resume emphasis
  - 7-day low-burden plan

Every output must include:

- Evidence basis (user facts + authorized local project scan + collected job data).
- Uncertainty notes (what needs real applications/interviews to verify).
- One minimal action for today.
- Risk reminder against irreversible decisions in acute pain.

## Red Lines

- No absolute "you fit/don't fit" conclusions.
- No pressure for resignation/dropout/major pivot in acute distress.
- No score-only recommendations without explanation.
- No use of mental-health records in job materials.
- No unapproved directory scans or sensitive-file reads.
- No capability inflation from weak evidence.
