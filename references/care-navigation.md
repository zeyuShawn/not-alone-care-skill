# Care Navigation

Use this file when the user asks about diagnosis, treatment, doctors, therapy, medication, hospital visits, or persistent symptoms.

## Boundaries

- Do not diagnose.
- Do not decide whether medication is needed.
- Do not give dosing, tapering, switching, or interaction instructions.
- Do not tell the user to avoid professional care.
- Do help prepare clear information for a clinician.

## When to Encourage Professional Help

Encourage professional evaluation when:

- Distress persists for days or weeks.
- Mood, anxiety, sleep, appetite, concentration, or energy impair daily life.
- The user cannot work, study, care for self, or maintain relationships.
- Panic attacks recur.
- Self-harm, suicidal thoughts, psychosis-like experiences, mania-like symptoms, substance misuse, or unsafe medication use appears.
- The user is considering stopping or changing medication.

## Appointment Prep Template

Offer to organize:

- Main concern in one sentence.
- Symptom timeline.
- Sleep, appetite, energy, concentration.
- Function impact.
- Anxiety/panic episodes.
- Self-harm or suicide thoughts, if present.
- Past diagnoses or treatment.
- Current medication and supplements, without advising changes.
- Substance use if relevant.
- Recent stressors.
- Questions for the clinician.

## Example Output

```text
我想咨询的是：最近情绪和焦虑明显影响生活。
持续时间：约 __ 天/周。
主要症状：__
睡眠/食欲/精力：__
功能影响：工作/学习/自理/社交方面 __
风险信号：有/无自伤或自杀想法；如果有，频率和是否有立即危险 __
既往治疗或用药：__
我想问医生：1) __ 2) __ 3) __
```

## Medication Questions

If the user asks about medication:

- Explain that medication decisions require a licensed clinician.
- Encourage contacting prescriber, pharmacist, emergency service, or poison control if urgent.
- Help draft questions.

Example:

> 我不能判断该不该停药或改剂量，但可以帮你把症状和担心整理成一段发给医生的话。

## Care-Seeking Message

Draft low-burden messages:

> 我最近情绪/焦虑已经影响睡眠和日常功能，想约一次评估。可以帮我安排精神科/心理咨询/全科医生的预约吗？
