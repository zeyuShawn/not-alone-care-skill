# Self-Help Modules

Use these only when the user is not in immediate danger. These are support exercises, not treatment.

## Module Selection

- Low mood, numbness, inability to start: use Behavioral Activation.
- Self-blame, rumination, distorted certainty: use CBT-style thought review.
- Panic or body alarm: use grounding.
- Worry loops: use worry container.
- Shame, hopelessness, loss of meaning: use ACT-style tiny value action.
- Interpersonal distress: use support-message drafting or relationship mapping.

## Behavioral Activation

Goal: restart action loops with tiny, realistic steps.

Steps:

1. Name the current state.
2. Pick one action under 2 minutes.
3. Make it concrete and physical.
4. Ask the user to report done/not done without shame.

Examples:

- Drink water.
- Open the curtain.
- Sit up.
- Put one dish in the sink.
- Send one neutral message.

Avoid saying the action will fix the mood.

## CBT-Style Thought Review

Use when the user has a painful thought like "I am useless" or "Nothing will ever change".

Steps:

1. Separate feeling from thought.
2. Ask for evidence for and against only if the user has capacity.
3. Create a softer, more accurate sentence.
4. Pair it with a small action.

Do not argue aggressively with the thought. Do not imply the user is irrational.

## Grounding for Panic

Use short exercises:

- Feet on floor.
- Name three visible objects.
- Exhale slightly longer than inhale for 3 rounds.
- Hold a cool object.
- Describe the room in neutral terms.

Do not over-focus on symptoms if it increases panic.

If the user reports possible medical emergency signs such as severe chest pain, fainting, blue lips, severe trouble breathing, new neurological symptoms, overdose, or symptoms that feel medically dangerous, advise contacting local emergency medical services or going to urgent/emergency care. Do not assume it is "just anxiety."

## Worry Container

Use for repeated worry loops.

Steps:

1. Write the worry in one sentence.
2. Mark it as solvable, partly solvable, or not controllable tonight.
3. If solvable, choose one next action.
4. If not controllable tonight, schedule a worry time.

## ACT-Style Tiny Value Action

Use when the user cannot make pain disappear.

Prompt:

> Even with this feeling here, what is one tiny action that moves 1% toward the kind of person you want to be today?

Keep it small and concrete.

## When to Stop Self-Help

Stop and route upward if:

- Self-harm or suicide signals appear.
- The user cannot stay safe.
- The user becomes more distressed by the exercise.
- Medication or medical danger emerges.
- The user reports severe functional collapse.

## Source Notes

Public sources such as NIMH describe psychotherapy, CBT, IPT, activity, routine, and trusted connection as potentially helpful parts of care. WHO describes digital interventions based on CBT, DBT, problem-solving therapy, and mindfulness as support, not replacement treatment, for suicidal thoughts.
